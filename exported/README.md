
# Red Canary Demo Request Form

This is a standalone HTML, CSS, and JavaScript implementation of the Red Canary demo request form. It was exported from a React/TypeScript application with Tailwind CSS.

## Files

- `index.html` - The main HTML file containing the structure of the form
- `styles.css` - All the styling for the form and page layout
- `script.js` - JavaScript to handle form validation, multi-step navigation, and form submission
- `birds.png` - Background image of Red Canary birds (you'll need to add this image file)

## Features

- Multi-step form with progress indicator
- Form validation at each step
- Toast notifications for errors and successful submission
- Responsive design for mobile and desktop
- Redirects to thank you page after submission

## Implementation Details

This form features:
- Three-step process for collecting user information
- Validations for required fields
- Progress bar showing current step
- Back button to navigate to previous steps
- Form data collection and submission
- Redirect to thank you page after successful submission

## Usage

1. Download all files to the same directory
2. Open `index.html` in a web browser
3. You'll need to add a `birds.png` file for the background image
